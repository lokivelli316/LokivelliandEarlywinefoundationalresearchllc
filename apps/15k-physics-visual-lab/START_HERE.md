# Start Here

1. Clone the parent repo with `--recurse-submodules`.
2. Serve the repository root over HTTP.
3. Open `apps/15k-physics-visual-lab/`.
4. Open **CONTROL BOARD** and inspect the `SME_MOND_THIRD_CLEAVE` tree.
5. Change `q_H` or `ζ`: the amplitude wall and visualization react immediately; release/change commits a receipt.
6. Move `p` away from `2`: the scientific status must switch the 9L throat from `CONDITIONAL` to `PARAMETRIZED`, while the visualizer uses the separately labeled fallback transition depth.
7. Open **RUN RECEIPTS** and use **VERIFY CHAIN**.
8. Use W/A/S/D/R/F + Q/E or mobile controls for 6DOF flight. Enter XR when the browser/device exposes the VR button.

A rendered frame is not scientific validation. The app's purpose is to make mutation consequences visible *and traceable*.
