# Lokivelli & Earlywine Foundational Research LLC

Public site. Single-page, static. No build step.

## Files
- `index.html` — the whole site
- `assets/images/hero.jpeg` — hero / throne logo
- `assets/images/favicon.png` — anvil badge favicon
- `.nojekyll` — tells GitHub Pages to serve the files as-is
